# Synthetic guideline corpus

These three Markdown documents were authored for this demo. They contain
synthetic review checklists, not validated clinical guidance, patient records,
or proprietary hospital material. No real PHI is used.

The authors dedicate these documents and their manifest metadata to the public
domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
This dedication applies to the guideline corpus, not automatically to repository
code. Every manifest entry records a stable document ID, title, source, license,
and relative Markdown path. Only manifest entries are ingested; this README is
excluded. Document SHA-256 hashes and section/chunk identifiers are added during
ingestion so citations identify the retrieved version.

Extraction supports UTF-8 Markdown body text and headings. It does not implement
PDF/OCR, web crawling, or arbitrary file formats. Keep content synthetic and
review any additional source's usage rights before adding it to the manifest.
